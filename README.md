# Real-Time Face Detection Video Streaming System

A containerised backend API that accepts a video feed, detects faces,
draws bounding boxes using Pillow (no OpenCV), stores ROI data in PostgreSQL,
and streams annotated frames back to a React frontend.

## Tech Stack
- FastAPI + WebSockets
- MediaPipe (face detection)
- Pillow (ROI drawing, no OpenCV)
- PostgreSQL + SQLAlchemy + Alembic
- React.js
- Docker + Docker Compose
